# Recorridos de distribución de viandas (CABA)

Página estática con los recorridos para 8 vehículos que salen de Av. Santa Fe 4320, en tres escenarios (100, 150 y 200 viandas por vehículo).

Para desplegar en Vercel: importar este repositorio; no requiere build (framework "Other", sin comando de build, directorio de salida `.`).
